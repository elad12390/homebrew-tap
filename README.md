## Open Task Manager

A native, open-source system monitor for macOS — [website](https://elad12390.github.io/open-task-manager/) · [source](https://github.com/elad12390/open-task-manager).

```sh
brew install --cask elad12390/tap/open-task-manager
```

The cask in `Casks/open-task-manager.rb` is updated automatically by the app's release workflow.
